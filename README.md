# OurCamp

Компактный голосовой клиент в духе TeamSpeak: лагеря (серверы) живут на компьютерах
пользователей, главное окно — дерево голосовых каналов («костров») с участниками, а чат
и стримы открываются отдельными окнами.

Макеты: <https://claude.ai/artifact/A9mZCWav7VeKur4eVfdwgA> (страница «Компактный клиент»).

## Состояние

Этап **M0 — фундамент** (см. [roadmap](docs/roadmap.md)):

- ✅ `crates/oc-audio` — аудиомикшер: громкость каждого участника 0–200 %, локальное
  заглушение, «выключить звук», лимитер, индикатор речи. Без зависимостей, 45 тестов.
- ✅ `crates/oc-invite` — ссылки-приглашения и одноразовый ключ админа с привязкой к
  сертификату сервера. Без зависимостей, 15 тестов.
- ✅ `apps/desktop` — клиент на Tauri 2 + React: главное окно по макету, меню громкости
  участника, вывод звука через микшер. Пока вместо настоящих собеседников звучат
  **синтетические голоса** — чтобы громкость, заглушение и индикатор речи можно было
  проверить на слух до подключения WebRTC (M2).

## Структура

```
crates/
  oc-audio/        микшер реального времени (Rust)
  oc-invite/       формат ссылок ourcamp:// (Rust)
apps/
  desktop/         клиент: React UI (src/) + нативная часть Tauri (src-tauri/)
docs/
  architecture.md  как устроена система целиком
  decisions/       записи о принятых решениях (ADR) — «почему так»
  roadmap.md       этапы
  development.md   как собрать и запустить
```
