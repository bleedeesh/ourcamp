# Roadmap

Номера этапов используются в комментариях кода («arrives in M2»), чтобы было видно,
где заглушка и когда она уйдёт.

| Этап | Что | Готово, когда |
|---|---|---|
| **M0** ✅ | Фундамент: монорепо, ADR, `oc-audio`, `oc-invite`, главное окно, вывод звука, синтетические голоса | собирается на Windows, громкость участников слышна и сохраняется |
| **M1** ✅ | Проверка стека на Windows и macOS; CI | `pnpm dev` работает на обеих ОС, CI зелёный (включая Miri для `oc-audio`) |
| **M2** ✅ | Голос: LiveKit Rust SDK, захват микрофона (cpal → AEC3 → шумодав → AGC), публикация/подписка, удалённые дорожки → микшер, Opus по ADR-0008. Локальный LiveKit для разработки. ADR-0009–0011 | двое разговаривают через локальный сервер; громкость каждого регулируется |
| **M3** | OurCamp Server: Rust (axum + SQLite), запуск и контроль LiveKit, TLS с самоподписанным сертификатом, ключ админа и приглашения (`oc-invite`), UPnP/NAT-PMP, окно сервера | лагерь поднимается одним установщиком, друг заходит по ссылке |
| **M4** | Профиль и адрес без посредников (ADR-0035, 0036): ник и аватарка при входе, «адрес для друзей» и VPN, домен с сертификатом, открытые серверы. Аккаунтов, друзей и лички нет | друг заходит на домашний сервер, сервер на хостинге и через Radmin VPN |
| **M5** | Окно чата: чат каналов сервера, фото, история | экран 9 |
| **M6** | Стримы (ADR-0049): захват SDK, H.264 через Media Foundation, окно просмотра на wgpu, звук стрима — отдельный источник со своей громкостью | экраны 11, 12 |
| **M7** | Настройки: устройства, голосом/по кнопке, порог, выбор шумодава (RNNoise/DeepFilterNet) | экран 13 |
| **M8** | Установщики, подпись кода, автообновление | установка в один клик на Windows/macOS |

## M7 по шагам (ADR-0057)

1. ✅ **Окно и профиль:** окно настроек, смена имени и аватарки, `PUT /api/v1/members/me/name`.
2. ✅ **Устройства (ADR-0066):** микрофон и вывод без перезапуска, возврат к выбранному, общая громкость.
3. ✅ **Как включается микрофон (ADR-0069):** голосом с порогом и полоской уровня или пока зажата клавиша, даже при свёрнутом окне (только Windows).
4. ~~**Остальные клавиши**~~ сняты: хватает клавиши «говорить» на вкладке «Звук» (ADR-0071).
5. **Шумодав и эхоподавление:** переключатели; RNNoise или DeepFilterNet, если разница слышна.

## M6 по шагам (ADR-0049)

На Windows этап готов; на macOS и Linux стримов пока нет.

1. ✅ **Стрим без окон:** кодировщик MFT, захват → LiveKit → зритель получает кадры (1080p60: 59,8 fps у
   зрителя, 4 % CPU клиента на 12 ядрах); команды `stream_*`, интерфейса пока нет.
2. ✅ **Подписка по запросу и LIVE:** `auto_subscribe` выключен, микрофоны клиент просит сам, `streaming` в снимке,
   значок в дереве у всех, даже вне голоса. Команда «смотреть стрим» появится с окном просмотра на шаге 3.
3. ✅ **Окно просмотра (ADR-0053):** дочернее окно с `wgpu` поверх страницы, панель, число зрителей, на весь экран,
   клик по LIVE. 1080p60: 58–60 fps у зрителя. Ползунок громкости неактивен до шага 5.
4. ✅ **Окно «Начать стрим» (ADR-0054):** экраны и окна, качество (и 1440p), частота, кнопка в главном окне.
5. ✅ **Звук стрима (ADR-0055):** process loopback без голосов собеседников, своё сведение 7.1 в стерео, источник микшера, громкость.
6. **Отложен (ADR-0056): macOS и Linux.** Кодировщики SDK, окно просмотра, звук. Вернуться, когда будет на чём проверять вживую.

## M5 по шагам (ADR-0044)

1. ✅ **Сервер:** база v7 (сообщения с номером в чате, фото по хешу), `GET|POST
   /api/v1/channels/{id}/messages`, `POST|GET /api/v1/photos`, событие `message` всем,
   `chats` в снимке, запрет говорить = и писать; методы в `oc-camp-client`.
2. ✅ **Клиент без окна:** команды Tauri (`chat_history`, `chat_send`, `chat_photo`,
   `chat_mark_read`), `camp://chat` всем окнам, прочитанное на устройстве с момента входа,
   счётчик на кнопке «Чат» (ADR-0045). Дочитывание пропущенного — в окне (шаг 3): ему видна
   дыра между прочитанным и последним `seq`.
3. ✅ **Окно чата** (отдельное окно, экран 9, ADR-0046): вкладки-чаты, сообщения по дням и
   по авторам, «Новые сообщения», лента назад, дочитывание пропущенного, фото (кнопка /
   вставка / перетаскивание, до 1600 px, просмотр), прочитано — когда видно, демо в браузере.
4. ✅ **Модерация чата** (ADR-0048): удалить своё / младших по рангу (база v8, событие
   `message_deleted`), ограничение частоты.

## M3 по шагам

Решения — ADR-0014 (пиннинг TLS для LiveKit), 0015 (ключ устройства), 0016 (устройство сервера),
0017–0022 (по шагам).
Каждый шаг заканчивается рабочим состоянием и тестами.

1. ✅ **`oc-server` headless:** axum + SQLite, самоподписанный сертификат, TLS на 7780,
   LiveKit в режиме `external` (Docker), ключ админа и приглашения из `oc-invite`.
2. ✅ **Вход:** ключ устройства (`oc-camp-client`), nonce + подпись отпечатка лагеря, сессия; токен комнаты от сервера (ADR-0018).
   Подключение приложения вместо dev-токенов — в шаге 4, вместе с каналами с сервера в UI.
3. ✅ **Пиннинг в клиенте:** свой `WsClient` для LiveKit + HTTPS к API лагеря через один
   верификатор; прокси сигнализации `/rtc` на сервере.
4. **Лагерь в клиенте:**
   - 4a ✅ ссылка `ourcamp://` → вход, список лагерей, каналы с сервера, голос через лагерь;
     dev-токены и `OC_IDENTITY` удалены (ADR-0020).
   - 4b ✅ присутствие во всех кострах и роли: сервер опрашивает LiveKit по loopback →
     WebSocket `/api/v1/events` клиентам (ADR-0021); одна копия клиента на профиль,
     разрыв комнаты сервером виден в окне.
5. ✅ **LiveKit `managed`:** дочерний процесс, перезапуск, свой API-ключ; не переживает
   сервер (job object / сторож на `sh`), бинарник — `pnpm livekit:fetch` (ADR-0022).
6. **Окно сервера** (Tauri, ADR-0023): статус, две ссылки, кто в лагере, трей.
   Сделано: ядро отдаёт `camp_state()`/`livekit_pid_changes()`, общий `packages/ui`,
   `apps/server` (окно, ссылки, кто где, трей, повторный запуск показывает окно).
   Осталось: проверка вживую (чек-лист в development.md).
7. **UPnP/NAT-PMP** и подсказка про ручной проброс портов + проверка доступности
   снаружи в окне сервера. За CGNAT («серый» IP) входящие невозможны — ретранслятор
   (relay/TURN) — отдельная ADR.

## После проверки M3 Димой (2026-10-28)

Решено с Димой; порядок — сверху вниз.

1. ✅ **Мелочи:** убрать «(вы)» в костре; «Покинуть лагерь» в клиенте (сервер забывает
   участника, `DELETE /api/v1/members/me`); системный костёр **AFK** (ADR-0025).
2. **Управление лагерем в окне сервера:** роли **владелец** (тот, кто запустил окно) →
   **админ** (каналы, название, роли) → **модератор** (кик, перенос в другой костёр, mute);
   назначаются в окне. Ключ админа и ссылка «для вас» уходят. Переименование лагеря,
   голосовые и текстовые каналы (по умолчанию `Voice` и `Chat`), удаление канала с людьми
   — сервер выводит их (LiveKit `DeleteRoom`), клиент говорит «костёр удалён».
   Ссылка для друзей остаётся. ADR-0026. По шагам:
   - ✅ роли и каналы в протоколе и базе (v4), Voice/Chat/AFK, ключ админа упразднён, живые
     название и костры у клиентов;
   - ✅ действия владельца в ядре (`manage.rs`) + окно: роли, название, каналы;
   - ✅ модерация из окна: выгнать (без бана), перенести, запретить говорить (ADR-0028);
   - ✅ перенос перетаскиванием, в окне и в клиенте (модераторы, админы; ADR-0029);
   - ✅ выгнать и запретить говорить из клиента для админов и модераторов, младших по рангу
     (меню участника, ADR-0033);
   - ✅ команды владельца для headless-сервера: `oc-server status`, `role`, `kick`… в
     работающий лагерь (ADR-0041).
3. **Без центрального сервиса** (решено 2026-10-29, ADR-0035, 0036) — порядок:
   1. ✅ ник и аватарка при входе, копии аватарок на серверах (база v6, ADR-0035);
   2. ✅ «Адрес для друзей» (локальная сеть / VPN — Radmin, Hamachi, Tailscale по маршруту,
      ZeroTier — как свой / внешний / свой), он же `node_ip` LiveKit (ADR-0037);
   3. ✅ **шаг 7 M3** — UPnP (свой), внешний IP, «серый» адрес, проверка изнутри; адрес у
      клиента обновляет новая ссылка (ADR-0039);
   4. ✅ открытые серверы (вход по адресу `ourcamp://host?fp=…`, ADR-0040); ✅ домен с настоящим
      сертификатом (ссылка без отпечатка: `ourcamp://ourcamp.kz`, `--tls-cert`/`--tls-key`,
      ADR-0042); ✅ сервер для Linux — архив со статическим `oc-server`, systemd, `install.sh`
      (`pnpm server:pack`, задача CI `server-linux`, ADR-0043).
4. ~~Короткие ссылки через accounts-сервис~~ — отменено ADR-0036: в ссылке IP или домен.
5. ✅ **Бренд «Ночь»** (ADR-0024): акцент `#8B7CF6`, костёр и иконки перекрашены.
