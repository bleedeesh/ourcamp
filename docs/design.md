# Дизайн

Макеты и кликабельный прототип: <https://claude.ai/artifact/A9mZCWav7VeKur4eVfdwgA>,
страница **«Компактный клиент»** (13 экранов). Остальные страницы — история поиска стиля.

## Ключевые решения
- Компактный клиент как TeamSpeak: главное окно 380×720 — дерево костров с участниками;
  чат, стрим, друзья, настройки — отдельные окна.
- Тема: нейтральный чёрный/тёмно-серый без синевы; фиолетовый «Ночь» из логотипа (ADR-0024) — только
  выбранное и главные действия; зелёный — только «в сети»; красный — выключено/выйти.
- Говорящий — фиолетовая рамка со свечением вокруг аватара.
- Шрифты: Onest (интерфейс), Nunito 800 (заголовки), Fredoka (логотип).
- Логотип — мультяшный костёр (с ADR-0024 — в фиолетовой палитре); на ≤24 px упрощённая версия без контура и искр.

Токены — `apps/desktop/src/styles/tokens.css`. Логотип в коде — `apps/desktop/src/ui/Campfire.tsx`.
