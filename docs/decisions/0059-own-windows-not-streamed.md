# 0059. Окна OurCamp нельзя выбрать для стрима

**Дата:** 2026-10-31 · **Статус:** принято, уточняет [0054](0054-stream-start-window.md)
**Код:** `src-tauri/src/stream/pipeline.rs` (`list_sources`, `is_ourcamp_window`, `is_ourcamp_program`)

## Контекст
ADR-0054 считала, что окон OurCamp в списке нет, потому что libwebrtc не показывает окна своего процесса. Это верно только для своей копии клиента. Окно сервера и другая копия клиента — чужие процессы, и они в списке были. Стримить интерфейс голосового клиента незачем: кто захочет его показать, покажет весь экран.

## Решение
- **Окно отсеивается по файлу программы его процесса:** `ourcamp-desktop.exe` и `ourcamp-server-app.exe`, без учёта регистра. Эти имена даёт cargo: `mainBinaryName` в настройках Tauri не задан.
- **Фильтр в `list_sources`, в Rust.** Окно «Начать стрим» получает уже готовый список.
- **Экраны не трогаем.** На стриме всего экрана окна OurCamp видны, если они открыты.
- **Если система не называет программу процесса, окно остаётся в списке.** Лучше лишняя строка, чем пропавшая игра.

## Отвергнутые варианты
- **По заголовку окна.** Заголовок «OurCamp» может быть у чего угодно, например у вкладки браузера с этой страницей, а у окна стрима заголовок другой.
- **По классу окна.** Он общий у всех приложений на Tauri, и окна чужих программ пропали бы.

## Последствия
- `stream_start` не проверяет этот запрет: команду вызывает только окно «Начать стрим», а оно берёт источники из списка.
- Если файл программы переименовать, окно снова появится в списке. Вреда от этого нет.
- При смене имени пакета или появлении `mainBinaryName` список имён надо обновить.

## Проверка
Юнит-тесты на имена файлов и на запрос программы процесса. Настоящие приложения (ADR-0047): два клиента и окно Edge. В списке каждого клиента окно Edge есть, а окон с «OurCamp» в заголовке нет, хотя у другого клиента заголовок именно такой.

**Не проверено вживую:** окно сервера. Запуск `ourcamp-server-app.exe` поднял бы настоящий сервер Димы из его каталога данных, поэтому для него проверено только имя файла.
