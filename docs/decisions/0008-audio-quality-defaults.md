# 0008. Параметры звука по умолчанию

**Дата:** 2026-10-27 · **Статус:** принято (реализация — M2)

| Параметр | Значение | Почему |
|---|---|---|
| Кодек | Opus, 48 кГц, моно, fullband | родная частота WebRTC, без ресемплинга |
| Битрейт голоса | 64 кбит/с, VBR | «сладкая точка» fullband-речи 28–40 кбит/с (RFC 7587) — берём с запасом ради чистоты; VBR при том же среднем качественнее CBR |
| Потери | inband FEC + RED | переживает потери пакетов в Wi-Fi без слышимых артефактов |
| DTX | выключен | экономит трафик, но обрезает начала фраз |
| Обработка микрофона | AEC3 → шумодав → AGC | порядок важен; шумодав строго один (два ухудшают звук) |
| Шумодав | DeepFilterNet («качественный»), RNNoise («лёгкий») — выбор в настройках | DeepFilterNet3 лучше по разборчивости, RNNoise легче для слабых ПК |
| Звук стрима | Opus стерео 128 кбит/с | музыка/игра, а не речь |
| Видео стрима | H.264 аппаратно, 1080p60, simulcast | NVENC/QSV/VideoToolbox — не грузит CPU во время игры |
| Частота устройства | 48 кГц f32 если доступно | см. `src-tauri/src/audio/output.rs` |
