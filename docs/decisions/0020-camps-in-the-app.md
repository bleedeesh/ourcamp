# 0020. Лагеря в приложении: вход по ссылке, список лагерей, профиль разработчика

**Дата:** 2026-10-27 · **Статус:** принято · заменяет [0010](0010-dev-room-tokens.md) ·
**Код:** `apps/desktop/src-tauri/src/camps.rs`, `apps/desktop/src/domain/camps.ts`

## Решение
- **Вход по ссылке** в приложении (макеты, экраны 3 и 8): вставить `ourcamp://…` →
  карточка лагеря (имя, число костров; для ключа админа — «вы станете админом») →
  «Как вас называть» → «Войти в лагерь». Имя — поле в форме, пока нет аккаунтов (M4).
  Клик по ссылке в браузере, открывающий приложение, — в M8 вместе с установщиком
  (регистрация схемы `ourcamp://` — работа установщика).
- **Хранилище** — папка данных приложения: `device.key` (ADR-0015) и `camps.json`
  (адрес, отпечаток = id лагеря, сессия, роль, кэш имени и каналов, текущий лагерь,
  отображаемое имя). Запись атомарная; повреждённый `camps.json` откладывается в
  `camps.json.bad`, приложение стартует без лагерей, а не падает.
- **Лагерь недоступен** — открывается из кэша с предупреждением: дерево видно, войти в
  костёр нельзя, пока сервер не вернётся.
- **Истёкшая сессия** — молчаливый повторный вход ключом устройства (приглашение не
  нужно: лагерь знает это устройство).
- **Голос** — токен комнаты и адрес только от лагеря (`Camps::room_access`).
  **Dev-токены (ADR-0010) и `OC_IDENTITY` удалены**; транспорт LiveKit в любой сборке
  запрещает открытый `ws://` (ADR-0019).
- **Второй клиент на одном ПК** (разработка) — `OC_PROFILE=<имя>` в debug-сборке:
  отдельная папка данных → отдельный ключ устройства → другой человек в лагере.
- **«Скопировать приглашение»** — эндпоинт `GET /api/v1/invites/current` (только
  участникам) отдаёт токен; ссылку клиент собирает из известных ему адреса и отпечатка.
  Копирование: Clipboard API, при отказе — выделение + `copy`, при отказе и его — ссылка
  показывается в сообщении.
- **Браузерный режим** (`DemoCampApi`) начинает без лагерей и «пускает» по любой
  похожей ссылке в демо-лагерь — для вёрстки экранов первого запуска.

## Отвергнуто
- **Отдельный экран «Как вас зовут»** при первом запуске — экран, который M4 выбросит.
- **Хранить список лагерей в `localStorage`** webview — сессии лагерей — секреты, им место
  рядом с ключом устройства, а не в хранилище браузерного движка.

## Последствия
- Присутствие видно только в своём костре до шага 4b (опрос LiveKit сервером и рассылка
  по WebSocket).
- В M4 имя придёт из аккаунта, а список лагерей — ещё и из accounts-сервиса.
