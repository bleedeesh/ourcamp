# 0040. Открытые серверы: вход по адресу, без приглашения

**Дата:** 2026-10-29 · **Статус:** принято · выполняет часть [0036](0036-server-address-and-links.md) ·
**Код:** `crates/oc-invite` (`Link`, `Address`), `crates/oc-server/src/store.rs` (`set_open`),
`apps/server/src/ui/FriendsLink.tsx`, `apps/desktop/src-tauri/src/camps.rs`

## Контекст
Публичный сервер (на хостинге, с доменом) должен пускать любого, у кого есть адрес, —
без секретного приглашения в ссылке. Свой сервер для друзей остаётся по приглашению.

## Решение
- **Переключатель «Вход: по приглашению / открытый»** в окне сервера, в headless —
  `--open` / `--invite-only` (без флага — как было в прошлый раз).
  - Флаг хранится в `meta` (`open`): схема базы не меняется, отсутствие флага значит
    «закрыт».
- **Открытый сервер пускает новых без приглашения** (`Store::login`). Старое приглашение
  по-прежнему работает. Закрыли снова — новым нужно приглашение, а участники остаются.
- **Ссылка открытого сервера — один адрес:** `ourcamp://host[:port]?fp=…`. В `oc-invite`
  появился `Link`: либо `Invite` (как раньше), либо `Address`. Так приглашение не стало
  необязательным полем во всём коде.
  - Пока отпечаток в ссылке нужен всегда. С доменом и настоящим сертификатом ссылка
    станет просто `ourcamp://ourcamp.kz` — следующий шаг ADR-0036.
- **Окно** показывает ту ссылку, что сейчас работает: у открытого сервера — адрес, у
  закрытого — приглашение. Под переключателем — что это значит.
- **Клиент:**
  - форма входа принимает адрес как ссылку;
  - превью показывает «Открытый сервер — приглашение не нужно» или, если сервер
    закрыт, «пускает только по приглашению»;
  - у сервера, вошедшего по адресу, тот же отпечаток, что и по приглашению, — это тот же
    сервер в списке.
- `CampInfo.open` и `CampState.open` в протоколе (по умолчанию `false`, старые клиенты не
  ломаются).

## Отвергнуто
- **Сделать приглашение `Option` в `Invite`** — 19 мест в коде и тестах про приглашение
  стали бы гадать, есть ли оно.
- **Отдельная схема базы** — один флаг в `meta` проще миграции.
- **Бан для открытых серверов сразу** — пока есть «выгнать» и «запретить говорить». Бан —
  отдельной записью, когда появятся первые настоящие открытые серверы.
