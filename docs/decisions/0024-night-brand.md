# 0024. Бренд «Ночь»: фиолетовый акцент и костёр в той же палитре

**Дата:** 2026-10-28 · **Статус:** принято · заменяет оранжевый акцент из `docs/design.md` ·
**Код:** `packages/ui/src/tokens.css`, `packages/ui/src/Campfire.tsx`, `apps/desktop/app-icon.svg`

## Контекст
Оранжевый акцент (#FF7A3D) и рыжий костёр Диме не нравились. Из четырёх вариантов
(«Угли», «Хвоя», «Закат», «Ночь») выбран «Ночь» — с условием оставить сам логотип-костёр.

## Решение
- **Акцент** `#8B7CF6`, мягкий фон `rgba(139,124,246,.16)`, текст на тёмном `#B3A8FF`, текст на
  акценте `#0F0B26` (контраст ≈ 6:1). Правило прежнее: акцент — только выбранное и главные
  действия; рамка говорящего — тоже акцентом.
- **Костёр** — та же геометрия, палитра ночи: пламя `#8B7CF6` → `#B3A8FF` → сердцевина `#ECE8FF`,
  поленья `#3E3470` с торцами `#6E62B8`, контур `#1B1633`, искры `#C4BBFF`.
- **Корона админа остаётся золотой** (`#FFB23F`): это смысл (роль), а не бренд, и на фиолетовом
  она различима лучше. Красный — опасность, зелёный — «в сети» — без изменений.
- **Иконки приложений** — из векторного `apps/desktop/app-icon.svg` (`tauri icon`), одни и те же
  для клиента и окна сервера. Растровый `app-icon.png` удалён.

## Отвергнуто
- «Угли», «Хвоя», «Закат» и новые формы логотипа (капля, друзья вокруг огня, палатка, круг).
