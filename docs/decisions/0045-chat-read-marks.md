# 0045. Прочитанное в чатах: на устройстве, с момента входа

**Дата:** 2026-10-29 · **Статус:** принято · M5 шаг 2, дополняет [0044](0044-chats.md) ·
**Код:** `apps/desktop/src-tauri/src/camps/chat.rs`, `apps/desktop/src/domain/chat.ts`,
`CampsController` (`unread`)

## Контекст
Кнопке «Чат» нужно число непрочитанного, а окну чата — где остановился человек.
Аккаунтов нет (ADR-0035), поэтому «прочитано» знает только устройство. У сервера про это
ничего не хранится.

## Решение
- **Хранится на устройстве:** `camps.json`, у каждого сервера `read`: чат → последний
  прочитанный `seq`. Отметка только растёт: старая отметка из другого окна или
  повторный вызов её не откатывают.
- **Первый вход — с этого момента.** При первом входе на сервер приложение берёт последнее
  сообщение каждого чата (`history`, по одному) и считает его прочитанным. Иначе вся
  история до тебя горела бы непрочитанной. При повторном входе (новая ссылка, тот же
  сервер) отметки остаются. Чат, созданный позже, начинается с нуля: всё в нём ново.
- **Своё сообщение — прочитано.** Пришло событие с твоим `authorId` — отметка двигается
  сама, и на устройстве, и во всех окнах.
- **Одно событие для всех окон:** `camp://chat` с `message` (с сервера) и `read`
  (отметка на устройстве). Окно чата (шаг 3) будет отмечать прочитанное, главное окно
  сразу обновит счётчик, и наоборот.
- **Последний `seq` чата:** из снимка (`CampState.chats`) и из событий `message`, всегда
  наибольший. Событие может обогнать снимок, который его ещё не учитывает, — счётчик не
  прыгает назад.
- **Счётчик:** сумма по текстовым каналам `max(0, последний − прочитанный)`. Удалённые чаты
  и голосовые каналы не в счёт. На кнопке — до «99+», для экранных чтецов — «Чат,
  3 непрочитанных».

## Отвергнуто
- **Хранить прочитанное на сервере** — тогда сервер знал бы, кто что читал. К тому же
  отметки нужны устройству, а не людям.
- **Считать с нуля при первом входе** — новичок видел бы сотни непрочитанных.
- **Отдельная команда «сколько непрочитанного»** — всё нужное уже есть в снимке и событиях.

## Последствия
- На двух устройствах одного человека прочитанное своё у каждого: ключ устройства — это и
  есть человек ([ADR-0015](0015-device-identity.md)).
