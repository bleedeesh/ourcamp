# 0036. Адрес сервера и ссылки: IP или домен, без посредников

**Дата:** 2026-10-29 · **Статус:** принято · продолжает [0035](0035-no-central-service.md),
меняет план коротких ссылок из roadmap

## Контекст
Короткие ссылки `ourcamp://join/K7QM-4XPA` предполагались через accounts-сервис, а его не
будет (ADR-0035). Сервер живёт на домашнем ПК, на хостинге или в VPN-туннеле (Radmin,
Hamachi, ZeroTier, Tailscale). При прямом подключении клиент так или иначе узнаёт адрес
сервера: скрыть IP можно только из текста ссылки. Вариант с DHT BitTorrent Дима отклонил.

## Решение
- **В ссылке IP или домен** (`oc-invite` понимает оба). Порт 7780 по умолчанию не пишется.
- **Отпечаток (`?fp=`) — только у самоподписанного сертификата** (домашний сервер, работает
  без настройки). Если у сервера на домене настоящий сертификат (Let's Encrypt), клиент
  проверяет его по домену, как браузер, и ссылка без отпечатка:
  `ourcamp://ourcamp.kz/join/7k2q…`. Сертификат — сначала файлы от хозяина (`certbot`),
  позже получение прямо в сервере (ACME).
- **Открытые серверы.** Переключатель «Вход: по приглашению / открытый». Открытому хватает
  адреса: `ourcamp://ourcamp.kz`.
- **«Адрес для друзей»** в окне сервера (и в конфиге headless). Сервер сам собирает
  варианты:
  - локальная сеть;
  - VPN-адаптеры (Radmin `26.x`, Hamachi `25.x`, ZeroTier, Tailscale `100.64/10`);
  - внешний IP через UPnP (шаг 7 M3);
  - свой домен или IP.

  Выбранный адрес идёт и в ссылку, и в LiveKit (`node_ip`), иначе голос уйдёт на
  недоступный адрес.
- **Динамический IP:**
  - бесплатный DDNS-домен хозяина (DuckDNS, No-IP) — ссылка вечная;
  - новая ссылка на сервер с тем же отпечатком обновляет его адрес у клиента вместо
    дубля в списке.

## Отвергнуто
- **Короткие коды через центральный реестр** — посредник (ADR-0035).
- **Адрес через Mainline DHT (pkarr)** — Дима отклонил; ссылка не короче, а первый вход
  медленнее.
- **Доверие при первом входе вместо отпечатка** — первый вход можно подменить.

## Последствия
Порядок работ:
1. ник и аватарка при входе (ADR-0035);
2. «Адрес для друзей» и VPN;
3. шаг 7: UPnP, внешний IP, проверка доступности, обновление адреса по отпечатку;
4. домен с сертификатом, открытые серверы, сборка headless под Linux.
