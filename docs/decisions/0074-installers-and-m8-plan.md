# 0074. Установщики и план M8

**Дата:** 2026-11-01 · **Статус:** принято.
**Код:** `dev/pack-installers.ts`, `apps/*/src-tauri/tauri.conf.json` (`bundle`), `apps/server/src-tauri/tauri.installer.json`

## Контекст
M8: установка в один клик. У проекта нет своих облачных сервисов (ADR-0035), есть два приложения (клиент и окно сервера) и `livekit-server`, который сервер запускает сам и ищет рядом с собой (ADR-0022).

## Решение
**Два отдельных установщика NSIS: клиент и сервер.** Большинству нужен только клиент, а сервер ставит один человек на компанию. Сервер несёт с собой `livekit-server`.

**Установка на пользователя (`currentUser`), без прав администратора.** Не нужен запрос UAC, обновляться можно без него. Программа ложится в `%LOCALAPPDATA%`. Выбор MSI отвергнут: он рассчитан на установку на машину и не даёт ничего нужного здесь.

**WebView2 ставит загрузчик Tauri, если его нет** (значение по умолчанию). На Windows 11 он есть всегда. Вшитый полный WebView2 добавил бы около 180 МБ ради редкого случая.

**`livekit-server` подключается отдельным конфигом** `tauri.installer.json`, а не в основном: `tauri-build` требует указанный бинарник при каждой сборке, а он не лежит в репозитории, и обычная `cargo build` без `pnpm livekit:fetch` перестала бы собираться.

**Страницы проверяются сборкой `tauri build --debug --no-bundle`:** она отдаёт встроенные страницы, как релизная (`http://tauri.localhost`, CSP), но понимает `OC_PROFILE`. Поэтому проверка не трогает настоящий профиль на машине разработчика.

## План M8
1. **Установщики Windows:** этот шаг.
2. **Ссылка открывает приложение:** клик по `ourcamp://…` в браузере запускает клиент и открывает форму входа, а запущенный клиент получает ссылку через `single-instance` (ADR-0020).
3. **Автообновление:** подпись обновлений своим ключом, это бесплатно, и раздача через GitHub Releases. Своего сервиса для этого не нужно.
4. **Выпуск из CI:** сборка установщиков по тегу и публикация в GitHub Releases. Тогда сборка станет воспроизводимой, а не «с машины Димы».
5. **macOS:** `dmg`, стримов там нет (ADR-0056), `livekit-server` собирается из исходников (ADR-0022). Проверить вживую не на чем.
6. **Подпись кода:** решает Дима, это деньги. Без неё Windows показывает SmartScreen «Неизвестный издатель», а macOS не даёт открыть без обхода Gatekeeper. Сертификат для Windows стоит от сотен долларов в год, Apple Developer — $99 в год.

Шаги 1–4 работают и без подписи: человек один раз нажимает «Подробнее → Выполнить в любом случае».

## Последствия
- Брандмауэр Windows спросит про сеть при первом запуске сервера: `livekit-server` и окно сервера принимают входящие соединения. Запрос от системы, установщик ничего не настраивает.
- Версия задаётся в двух `tauri.conf.json`; при выпуске их надо менять вместе.
