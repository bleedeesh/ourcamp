# 0057. Окно настроек и план M7

**Дата:** 2026-10-31 · **Статус:** принято
**Код:** `src/ui/settings/`, `src/domain/settings.ts`, `src-tauri/src/windows.rs`, `src-tauri/src/camps.rs` (`set_name`), `crates/oc-server/src/api.rs` (`put_name`)

## Контекст
M7 — настройки, экран 13 макета: окно с вкладками «Звук», «Клавиши», «Профиль». Шестерёнка в главном окне до сих пор неактивна. Первый шаг ставит окно и вкладку «Профиль», остальные наполняются следующими шагами.

Ник сейчас меняется только в форме входа, а известен серверу только с момента входа: повторный вход случается лишь при истёкшей сессии. Значит, для вкладки «Профиль» серверу нужен отдельный запрос.

## Решение
- **Отдельное окно `settings`** (720×600, рядом с главным), как чат и «Начать стрим». Ему не нужен `CampsController`: окно говорит с Rust напрямую через `CampApi`.
- **`PUT /api/v1/members/me/name`.** Правила имени одни на вход и на смену (`oc_proto::clean_name`), изменение расходится снимком, как и аватарка.
- **Имя догоняет серверы как аватарка.** Устройство помнит для каждого сервера, какое имя тот получил (`name_sent`). Открытый сервер узнаёт сразу, остальные — когда их откроют. Без сети имя всё равно сохраняется на устройстве.
- **`profile://changed`.** Главное окно обновляет форму входа, когда профиль поменяли в окне настроек. Имя, уже набранное в форме, не затирается.
- **Без строки `@имя` и кнопки «Выйти из аккаунта» из макета.** Аккаунтов нет (ADR-0035).
- **Кнопка «Сохранить» для имени.** Сохранение на каждую букву слало бы запрос серверу и меняло имя у всех на лету.

## План M7
1. **Окно и профиль:** этот шаг.
2. **Устройства:** выбор микрофона и вывода без перезапуска, общая громкость. При смене вывода пересоздаётся микшер вместе с опорным сигналом для AEC.
3. **Как включается микрофон:** голосом с порогом и полоской уровня или по кнопке.
4. **Клавиши:** работают при свёрнутом окне. Для «говорить по кнопке» нужна проба: обычная глобальная клавиша забирает нажатие у других программ.
5. **Шумодав и эхоподавление:** переключатели из макета. RNNoise или DeepFilterNet подключаются, только если разница с шумодавом WebRTC слышна при сравнении (ADR-0009).

## Отвергнутые варианты
- **Менять имя повторным входом.** Вход требует новой подписи и создаёт ещё одну сессию ради одного поля.
- **Вкладки внутри главного окна.** В макете это отдельное окно, а главное окно 380 px для них узкое.

## Последствия
- До шага 2 и шага 4 вкладки «Звук» и «Клавиши» говорят, на каком шаге появятся. Окно открывается на «Профиле»; со второго шага первой станет «Звук».
- Новое имя участника в голосе приходит снимком, а не через LiveKit: токен комнаты несёт старое до следующего входа в канал. Дерево берёт имя из снимка, поэтому этого не видно.
