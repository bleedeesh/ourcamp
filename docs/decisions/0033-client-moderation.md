# 0033. Модерация из клиента: выгнать и запретить говорить по рангу

**Дата:** 2026-10-28 · **Статус:** принято · продолжает [0028](0028-moderation.md),
[0029](0029-drag-to-move.md) · **Код:** `crates/oc-proto` (`Role::governs`),
`crates/oc-server/src/api.rs`, `apps/desktop/src/ui/VolumeMenu.tsx`

## Контекст
Владелец модерирует из окна сервера (ADR-0028). Переносить из клиента админы и модераторы
уже могут (ADR-0029). Выгнать и запретить говорить из клиента было нельзя, а владельца на
связи может не быть.

## Решение
- **Право** (`Role::governs`, то же в `roster.ts`): выгнать и запретить говорить можно
  только того, кто **ниже рангом**. Модератор — участников, админ — модераторов и
  участников. Модератор не выгонит модератора, админ — админа, себя — никто. Это может
  только владелец из окна. Так модераторы не воюют друг с другом. Перенос мягче, для него
  правило прежнее: свой ранг и ниже.
- **API:** `DELETE /api/v1/members/{id}` (выгнать), `PUT /api/v1/members/{id}/silenced`
  `{ silenced }`. Ответ 204, ошибки `forbidden` / `not_found`. Сервер проверяет право сам и
  дальше действует, как владелец (`Manager`): адресное `kicked`, права LiveKit.
  - Если при «выгнать» LiveKit не ответил, это всё равно успех: участник уже удалён, а его
    приложению сказано уйти.
  - Если при «запретить» LiveKit не ответил — `internal`: просивший не должен думать, что
    человека больше не слышно.
- **Где в клиенте:** в меню участника (клик по человеку) под громкостью появляется раздел
  модерации, только если есть права:
  - «Перенести в канал» — список каналов; это и перенос с клавиатуры;
  - «Запретить / Разрешить говорить»;
  - «Выгнать с сервера» — с подтверждением в самом меню.

  Результат приходит снимком лагеря. «Выгнать» подтверждается уведомлением.
- Отказ сервера объясняется словами: «Это может только тот, у кого роль выше…».

## Отвергнуто
- **Модератор над модератором** (как перенос) — тогда любой модератор выгоняет любого, и
  роль ничего не защищает.
- **Отдельное контекстное меню модерации** — второе меню на того же человека. Громкость
  и модерация открываются одним кликом.
