# 0048. Удаление сообщений и лимит частоты

**Дата:** 2026-10-31 · **Статус:** принято · M5 шаг 4, дополняет [0033](0033-client-moderation.md), [0044](0044-chats.md), [0046](0046-chat-window.md) ·
**Код:** `crates/oc-server/src/store/chat.rs`, `crates/oc-server/src/api/chat.rs`,
`apps/desktop/src-tauri/src/camps/chat.rs`, `apps/desktop/src/domain/chat-window.ts`, `src/ui/chat/Feed.tsx`

## Контекст
Чату нужно убирать лишнее и не давать одному участнику завалить всех сообщениями.

## Решение
- **Кто удаляет:** автор — своё; модератор и админ — сообщения тех, кто ниже рангом
  (`Role::governs`, как выгнать и запретить говорить, ADR-0033). Ушедший автор считается
  обычным участником. Запрет говорить своё удалять не мешает.
- **Что остаётся (база v8):** строка с пометкой `deleted`. Текст и фото стираются по-настоящему,
  фото уходит при следующей чистке ненужных. Номер остаётся занят: новые сообщения его не
  получат, подсчёт непрочитанного и поиск пропусков (ADR-0044) работают как раньше.
- **Доставка:** `DELETE /api/v1/channels/{id}/messages/{seq}`, событие `message_deleted` всем,
  в клиенте `camp://chat` с `deleted`. Повторное удаление — не ошибка и без события.
- **Пропущенное удаление** номером не заметить. Когда сервер снова доступен, окно перечитывает
  последнюю страницу открытых чатов; более старое обновится при следующем открытии окна.
- **В ленте удалённого нет совсем**, без строки «сообщение удалено».
- **Подтверждение на месте:** корзина при наведении или правый клик, затем «Удалить для всех?».
  Вернуть сообщение нельзя. С выделенным текстом правый клик оставляет меню для копирования.
- **Лимит частоты:** на участника 10 сообщений сразу, затем 1 в секунду; фото и сообщение
  считаются отдельно. Сверх лимита — `TooFast` (429), в окне «Слишком быстро», черновик остаётся.
  Счётчики в памяти сервера: перезапуск их сбрасывает, это безвредно. Хранятся по участникам,
  поэтому память ограничена их числом.

## Отвергнуто
- **Удалять строку целиком** — номер освободился бы, а непрочитанное и поиск пропусков
  опираются на непрерывные номера.
- **Лимит на весь сервер** — один спамер мешал бы всем остальным.
- **Отдельная кнопка «очистить чат»** — можно удалить сам чат в окне сервера.

## Последствия
- Непрочитанное удалённое сообщение считается в счётчике, пока чат не открыт: номер занят.
  После открытия счётчик обнуляется.
- Окно сервера сообщения не показывает, поэтому владелец удаляет их только из клиента, как
  участник с ролью.
