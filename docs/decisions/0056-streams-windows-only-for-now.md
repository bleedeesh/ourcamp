# 0056. Шаг 6 M6 отложен: стримы пока только на Windows

**Дата:** 2026-10-31 · **Статус:** принято, уточняет [0049](0049-streams-plan.md)
**Код:** `apps/desktop/src-tauri/src/stream/mod.rs` (модуль `other`)

## Контекст
Шаг 6 плана M6 — стримы на macOS и Linux. Проверить их вживую сейчас не на чем: у Димы нет ни Mac, ни рабочего стола с Linux, а в CI нет экрана, звука и окна. Там можно только собрать код и прогнать тесты без настоящего захвата.

На этих системах это не одна правка, а три отдельных куска платформенного кода:
- **Отправка:** общий конвейер с кодировщиками SDK вместо Media Foundation. Захват SDK на этих системах у нас ни разу не запускался; на macOS ему нужно разрешение на запись экрана, на Linux — PipeWire или X11.
- **Окно просмотра:** на Windows это дочернее окно с `wgpu` (`surface.rs`, ADR-0053). На macOS нужен `NSView`, на Linux отдельное решение для X11 и Wayland.
- **Звук:** process loopback есть только на Windows. Другим системам нужен свой захват без голосов собеседников, иначе зрители услышат сами себя.

## Решение
Шаг 6 откладывается до появления машин для проверки. M7 идёт следующим, M6 считается готовым для Windows.

На macOS и Linux всё остаётся как сейчас: голос работает, `stream_start` и `stream_watch` отвечают, что стримы на этой системе появятся позже, значок LIVE виден.

## Отвергнутые варианты
- **Написать всё и проверить только в CI.** Много `unsafe` и платформенного кода, который никто ни разу не запускал. Сборка в CI не показывает ни картинку, ни звук, а Дима хочет качество без костылей.
- **Только отправка.** Её можно было бы частично проверить с настоящим LiveKit, но настоящий захват всё равно никто не увидит, а смотреть на этих системах было бы нельзя.

## Последствия
- На macOS и Linux стримить и смотреть нельзя. Участник с такой системой видит LIVE у других, но открыть стрим не может.
- M8 (установщики) выйдет на macOS без стримов, это надо сказать в описании версии.
- Заглушка в `stream/mod.rs` остаётся с пометкой «M6, шаг 6», `wgpu` и `windows` подключены только под Windows.

## Когда вернуться
Когда появится Mac или Linux для проверки. Начать стоит с отправки: сделать путь с обычными кадрами для кодировщиков SDK так, чтобы он собирался и на Windows и его можно было проверять здесь же с настоящим LiveKit. Выбор между ним и Media Foundation — в одном месте. Для проверки сборки под Linux можно обойтись контейнером Docker, для настоящего захвата — нет.
