# 0032. Своя иконка у окна сервера

**Дата:** 2026-10-28 · **Статус:** принято · **Код:** `apps/server/app-icon.svg`,
`apps/server/src-tauri/icons/`

## Контекст
Окно сервера использовало иконку клиента. На ПК, где запущены оба, их не различить ни в
панели задач, ни в трее.

## Решение
Тот же костёр в палитре «Ночь» (ADR-0024), чуть меньше и левее. В правом нижнем углу —
фиолетовый значок «сервер»: два блока стойки с зелёными огоньками, отделённые от костра
вырезом цвета фона. Значок крупный, чтобы читаться и в 16–32 px. Исходник —
`apps/server/app-icon.svg`, набор строит `pnpm tauri icon app-icon.svg` в `apps/server`.
В репозиторий идут те же пять файлов, что у клиента.

Тот же значок стоит и внутри окна: в заголовке и в карточке статуса (`<Campfire server />`,
`packages/ui/src/Campfire.tsx`). Иначе окно сервера изнутри выглядит как клиент.

Иконку окна и трея Tauri на Windows берёт из ресурса exe. Если панель задач после
пересборки показывает старую картинку, это кэш иконок Проводника для того же пути к exe.
Его обновляет `ie4uinit.exe -show` (или выход из системы).

## Отвергнуто
- **Другой цвет костра** (например, зелёный) — ломает единый бренд.
- **Подпись «S» или «SRV»** — в 16 px не читается.
