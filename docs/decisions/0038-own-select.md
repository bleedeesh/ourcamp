# 0038. Свой выпадающий список вместо системного

**Дата:** 2026-10-29 · **Статус:** принято · **Код:** `packages/ui/src/Select.tsx`, `select.ts`

## Контекст
`<select>` в webview раскрывает системный список: белый или серый, со шрифтом ОС, без
второй колонки. В тёмной теме окна он смотрится чужим («всё криво»). А для «Адреса в
ссылке» нужен IP справа приглушённым цветом, этого `<option>` не умеет.

## Решение
- Свой `Select` в `packages/ui` для обоих окон: поле с выбранным значением и список в
  стиле приложения. Справа у пункта может быть приглушённый `detail` (IP). У выбранного —
  галочка, наведённый подсвечен.
- Доступность — шаблон WAI-ARIA «select-only combobox»: кнопка `role="combobox"` с
  `aria-expanded`, `aria-activedescendant`, список `role="listbox"`, пункты `role="option"`.
  Фокус всегда на поле.
- Клавиатура: ↑/↓ (без перескока через край), Home/End, PageUp/PageDown, Enter и Пробел
  выбирают, Esc закрывает, Tab закрывает и идёт дальше. Поиск по первым буквам: повтор
  буквы листает совпадения. Логика клавиш — чистые функции в `select.ts` с тестами.
- Список `position: fixed` под полем или над ним, если внизу не хватает места. Карточка
  с прокруткой его не обрезает. Закрывается при прокрутке, изменении размера и клике мимо.
- `onOpen` — сигнал при открытии: окно сервера ищет сети заново (включённый после старта
  VPN).
- Заменены: «Адрес в ссылке» и роль участника в окне сервера.

## Отвергнуто
- **Стилизовать `<select>`** — раскрытый список рисует ОС, CSS до него не достаёт.
- **Библиотека (Radix, Headless UI)** — задача на пару сотен строк (ADR-0007).
