# 0001. Монорепозиторий

**Дата:** 2026-10-27 · **Статус:** принято

## Контекст
Клиент (React + Rust), сервер лагеря (Rust), общий сервис аккаунтов (TS) и общие
крейты (`oc-audio`, `oc-invite`) меняются вместе: формат ссылки нужен и клиенту, и серверу.

## Решение
Один репозиторий. Rust — Cargo workspace в корне (`crates/*`, `apps/*/src-tauri`, позже
`server/*`). JS/TS — pnpm workspace (`apps/*`, позже `services/*`).

`default-members` в `Cargo.toml` — только платформонезависимые крейты: `cargo test`
в корне не требует тулчейна webview.

## Последствия
- Изменение протокола — один коммит на обе стороны.
- Общий `Cargo.lock` и общие lint-правила (`[workspace.lints]`, `clippy.toml`).
